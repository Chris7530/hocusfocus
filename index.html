Cómo conectar · How to connect

  1. En el iPhone que graba: Blackmagic Camera → Preferencias → Network Access → Enable HTTP Server.
    On the recording iPhone: Blackmagic Camera → Settings → Network Access → Enable HTTP Server.
  2. Los dos dispositivos en la misma Wi‑Fi (o el hotspot del iPhone que graba).
    Both devices on the same Wi‑Fi (or the recording iPhone's hotspot).
  3. En Hocus Focus, toca la cámara que aparece en la lista, o escribe la dirección (p. ej. 192.168.1.10:4444).
    In Hocus Focus, tap the camera in the list, or type the address (e.g. 192.168.1.10:4444).

Problemas frecuentes · Troubleshooting

  • No aparece la cámara: comprueba que el servidor HTTP esté activado y que ambos estén en la misma red. Usa "Buscar en la red" o la dirección manual.
    Camera not listed: check the HTTP server is on and both devices share a network. Use "Scan network" or the manual address.
  • El foco no se mueve: en Blackmagic Camera el foco debe estar en manual.
    Focus does not move: focus must be set to manual in Blackmagic Camera.
  • Permiso de red local: si lo rechazaste, actívalo en Ajustes → Hocus Focus → Red local.
    Local network permission: if declined, enable it in Settings → Hocus Focus → Local Network.
